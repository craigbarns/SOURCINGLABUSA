Définitions et format d’import

Opportunités qualifiées : qualification humaine dans le registre commercial, séparée par pilier. Conversions : soumissions effectivement acceptées, dédupliquées ; n’indiquent ni vente ni opportunité qualifiée. Organique : préciser États-Unis, non-marque et moteur. Citations IA : préciser le rapport Bing ou le panel réellement testé ; une citation n’est pas un classement.

CSV UTF-8 avec en-tête exact ci-dessous. Les champs entre guillemets peuvent contenir virgules et retours à la ligne. Le modèle vide contient seulement l’en-tête. Import cumulatif : les lignes déjà présentes à l’identique sont ignorées. Une valeur vide est conservée comme non mesurée. L’import complet est annulé si une ligne est invalide.
